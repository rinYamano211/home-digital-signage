# 筐体要件・実測寸法・取付条件

Issue #19の成果物。[hardware.md](hardware.md)第10章の筐体方針を前提に、CAD設計（#20）へ引き継ぐ実測値・要件・制約・未確定事項をまとめる。製品選定（#1）は見直さない。ソフトウェアのMVP要件は変更しない。

- 筐体はv1.0の範囲（[requirements.md](requirements.md)）。実際の印刷・組立は#19〜#21の必須条件ではない。
- 強度・温度・組立適合性は実機で検証していない。この文書の数値は、CADの前提とする実測値と設計案である。
- 方針の決定は[#19のコメント](https://github.com/rinYamano211/home-digital-signage/issues/19#issuecomment-7100937208)に記録した。

## 1. 前提と決定事項

hardware.md第10章で決まっていること：

- 前面フレーム＋左サイドカバー（Displayの端子が正面から見て左）。
- 前面側メインシャーシ＋リアカバーの2ピース構造。両者はネジで接合する。
- Displayは背面から挿入し、下部の固定穴2か所を主固定とする。上・左右は脱落防止と位置決めのみ。
- Pi 5とActive CoolerはDisplay背面のマウント部に取り付ける（リアカバーには取り付けない）。
- 通気は下部（主吸気）・上部（主排気）・背面（補助）の3か所。
- 壁掛けは背面2点支持。卓上は着脱式スタンド。

#19で決めたこと（2026-11-23）：

| 印刷         | 実家の3Dプリンタを使う。部品は分割しない（造形範囲が足りるという現時点の前提。機種・造形サイズ・材料は未確認で、#20で確かめる）   |

## 2. 測定の方法

- 2026-11-26〜27にユーザーが実測した。道具はデジタルノギス（150mmまで）、直尺、キッチンスケール。
- 寸法は画像から推定していない。写真は記録としてのみ使った。
- 単位はmm・g。3回測った値は平均を小数1桁で書く。1回だけ測った値は「1回」と書く。
- 値の種類を区別する。特に書いていない値は**実測値**。実測値から算出した値は「**計算値**」、確かめていない前提は「**仮定**」と書く。
- 原点は、Displayを**正面から見て左下の角**とする。X＝右、Y＝上、Z＝正面（ガラス面）から背面への奥行き。

## 4. 要件・制約

### 4.1 構成

- メインシャーシとリアカバーの2ピース。印刷範囲が足りるため、どちらも分割しない。
- メインシャーシは、前面フレーム・左サイドカバー・Displayの保持・内部配線の固定・リアカバー用のネジボスを持つ。
- リアカバーは、壁掛け部・通気口・卓上スタンドの取付部を持つ。

### 4.2 Displayの保持と脱落防止

- 下部の固定耳2つを主固定にする。
- 耳の位置は、Displayの外形（幅228.0。耳の外側の端面はDisplayの側面と面一）と、耳の寸法（8.4×8.4）を基準にする。
- 耳の外形は、8.4×8.4の長方形を外枠として扱い、隙間を取ってよい。下フレームの内側に、耳とネジボスが入る空間を設ける。
- 固定穴の位置は、実測値（穴の直径3.0、外側の端面から穴の縁まで約2.8）から#20で暫定値を決め、仮定と明記する。
- 測定と造形の誤差は、ネジ穴を左右方向の長穴にする、隙間を取る等で吸収する。
- 実際に組み付けられるかは、試作・組立で確かめる。
- 前方への脱落は、フレームを前面に被せて止める。被せる幅は、ベゼル（上4.4・下7.0・左4.3・右7.0）より小さくし、表示領域にかけない。
- 上と左右は、爪または後付けの部品で、位置決めとガタつきの抑制をする。
- リアカバーを外しても、Display・Piが落ちない。

### 4.3 内部の空間

- 内部の奥行きは、ガラス前面から39.4（PiのUSBポート。仮定を含む計算値）に、通気の余裕と測定の不確かさの余裕を加えて決める。
- Active Coolerは上面から吸気する。Coolerの上に、リアカバーとの隙間を設ける（量は#20で決める）。
- Piの下端から、電源のUSB-CプラグとMicro HDMIプラグが下へ出る（基板の下端から26.5）。基板の角がY＝24.7にあるため、プラグとケーブルの曲がりがDisplayの下端より下まで届く。Pi電源のケーブルは、中央下の配線口からそのまま外へ出す。Micro HDMIケーブル（PiとDisplayをつなぐ内部の配線）は、下フレームの内側で折り返すことを原則とする。内側に収まらない場合は、例外として下面の配線口から一度外へ出してよい（ユーザー判断）。

### 4.4 左サイドカバーと配線口

- 左サイドカバーの内側は、左側面から49.1（プラグ＋ケーブル）に余裕を加えた幅にする。
- 端子は左側面のY＝33.5（電源）とY＝55.5（HDMI）。Z＝8.9は基準面が未確認のため、サイドカバーの開口や逃げは奥行き方向に余裕を持たせる。
- 配線口は下面に2つ設ける。Display電源用は正面から見て左下（Displayの端子の下）、Pi電源用は中央下（Piの電源端子の下）。以前の「背面下部か左側面」から変更した（2026-11-27）。
- 各配線口は、通すケーブルのプラグ（Pi電源26×12×7、Display電源23×11×6.8）が通る大きさにする。Micro HDMIケーブルを外へ出す場合は、そのプラグ（23.3×14.7×6.9）も通る大きさにする。
- 2本を壁際でスリーブ（外径13）にまとめるため、筐体の外でまとめやすい位置関係にする。
- 配線口の縁は角を丸め、ケーブルの被覆を傷つけない。
- ケーブルを引っ張っても端子に力がかからないよう、筐体の中にケーブルの固定点（結束バンドを通す穴等）を設ける。

### 4.5 通気

- 下部から吸気し、上部から排気する。背面は補助とする。
- 壁掛けでも卓上でも、通気口が塞がれない。
- 開口の形と面積は#20で決める。温度は実機で検証していない。

### 4.6 保守性

- リアカバーを外せば、microSDの抜き差し、ケーブルの抜き差し、Display背面のボタン操作ができる。
- Displayは電源が入ると自動で点くため、通常の運用でボタンを押すための穴は設けない。
- 開け閉めするネジは同じ規格にそろえる。

### 4.7 壁掛け・卓上

- リアカバーにキーホールを2か所設ける。ピクチャーレールのフック・ワイヤーにも掛けられる形を目指す。共通の構造で両立できるか、接続の方法、強度は未検証で、#20で確かめる。
- 完成重量は約0.5kgに筐体の重さを加えた値になる。フック・レールは、耐荷重の表示が完成重量を上回るものを使う。
- 卓上スタンドは着脱式とし、リアカバーに取付部を設ける。角度は#20で決める。スタンド使用時も下部の吸気口を塞がない。

### 4.8 安全性

- ACアダプタは筐体の外に置く。筐体の中は5Vの配線だけにする。
- Active Coolerの周りを密閉しない。
- 強度・温度は未検証であることを、#20・#21の成果物にも記録する。

### 4.9 材料・印刷・公差

- 材料はPETGを第一候補とする。PLAは、Piの熱が長く続くと柔らかくなるおそれがある。実家のプリンタで使える材料を確認して決める。
- 造形範囲は、228×148.6のDisplayを囲むフレームが1回で印刷できることを**仮定**する。プリンタの機種・造形サイズは未確認で、#20で確かめる。
- 差し込み部の隙間は0.3〜0.5を目安とし、#21で印刷条件に合わせて見直す。
- 概算の値（固定耳の間隔、出っ張り、HDMIの曲げ）は、穴を長穴にする・余裕を持たせる等で吸収する。

### 4.10 RTC Battery

- 任意（後付け可能）とする。Piの近くに、電池とケーブルを置ける空きを残す。
- 実物は持っていないため、寸法は公式資料の参考値とし、実物では確認していないと記録する。

## 6. #20への引き継ぎ

- 固定耳と固定穴：Displayの外形と耳の寸法を基準に配置する。穴の位置は暫定値を決めて仮定と明記し、長穴・隙間で誤差を吸収する。
- 内部の奥行き：39.4（仮定を含む計算値）に、通気と不確かさの余裕を加える。
- 左サイドカバー：左側面から49.1の出っ張りと、端子のZの不確かさを考えて余裕を取る。
- 配線口：下面に2つ（Display用は正面から見て左下、Pi用は中央下）。Pi下側のプラグの逃げと、Micro HDMIを外へ出す例外を考える。
- 壁掛け：キーホールとピクチャーレールの両立を検討し、接続方法・強度を確かめる。
- 印刷：プリンタの機種・造形サイズ・材料を確かめ、分割しない前提が成り立つかを確かめる。
- 未検証の事項（温度・強度・組立適合性）を、#20の成果物にも記録する。
