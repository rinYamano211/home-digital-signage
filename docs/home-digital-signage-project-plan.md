# Home Digital Signage

## 1. プロジェクト概要

Raspberry Pi とディスプレイを利用した、個人向けのデジタルサイネージを開発する。

自宅に設置したディスプレイへ、時計を常時表示しながら、予定・気温・天気予報などの情報を自動的に切り替えて表示する。

将来的にはスマートフォンやPCから表示内容を管理できるようにし、クラウドとRaspberry Piを組み合わせたIoT/エッジシステムへ発展させる。

本プロジェクトでは、単にサイネージを完成させるだけでなく、開発を通じて以下の技術領域を学習する。

- Raspberry Pi / Linux
- 組み込み・エッジデバイス
- Webアプリケーション
- API / HTTP通信
- クラウド
- データベース
- デバイスとクラウド間の通信
- CI/CD・テスト・監視
- AI駆動開発
- アジャイル開発

---

## 2. プロジェクトの目的

### 2.1 Raspberry Piを使う

Raspberry Piを実際のエッジデバイスとして利用し、Linux上でアプリケーションを動作させる。

### 2.2 デジタルサイネージの仕組みを理解する

「コンテンツを作って画面に表示する」だけではなく、

- コンテンツ管理
- 表示制御
- データ取得
- ネットワーク通信
- デバイス側でのキャッシュ
- 自動起動
- 障害時の復旧

など、デジタルサイネージを構成する要素を実際に実装する。

### 2.3 組み込み・クラウド技術を学ぶ

Raspberry Pi側のソフトウェアとクラウド側のサービスを連携させ、エッジデバイスとクラウドが連携するシステムを構築する。

## 5. 表示仕様

### 5.1 時計

時計は常時表示する。

イメージ：

```text
┌─────────────────────────────┐
│                             │
│                         22:48│
│                             │
│                             │
│        現在の表示内容        │
│                             │
│                             │
└─────────────────────────────┘
```

時計は他のコンテンツが切り替わっても画面上に表示し続ける。

### 5.2 その他の情報

時計以外の情報は自動的に切り替える。

例：

```text
予定
 ↓
気温
 ↓
天気予報
 ↓
写真
 ↓
予定
 ↓
...
```

切り替え時間は設定可能にすることを検討する。

例：

- 予定：10秒
- 気温：10秒
- 天気予報：15秒
- 写真：10秒

### 5.3 拡張性

新しいコンテンツを追加する際に、既存機能への影響を最小限にする。

理想的には、

```text
Content
├── Clock
├── Schedule
├── Temperature
├── Weather
├── Photo
└── NewContent
```

のように、コンテンツ単位で独立して追加できる構造を目指す。

## 7. 最終目標

### 個人で不便なく日常利用できること

企業向けの大規模なサイネージシステムではなく、自宅で継続的に利用できる品質を目標とする。

最低限、以下を満たす。

- Raspberry Piの電源を入れると自動起動する
- ネットワークに接続すると必要な情報を取得できる
- 時計が常時表示される
- 複数のコンテンツを自動切り替えできる
- 一時的にネットワークが切れても表示が破綻しない
- Raspberry Piを再起動しても自動復旧する
- 表示内容を簡単に追加・変更できる
- 将来的にスマートフォンから操作できる
- 長時間稼働できる

## 8. ハードウェア予算

総予算は **50,000～60,000円程度** を目標とする。

できるだけ既製品・低コストな構成を選択し、必要以上に高性能な機材は購入しない。

### 必要なもの

| 項目 | 必須 | 予算目安 | 備考 |
|---|---:|---:|---|
| Raspberry Pi | ○ | 要調査 | 性能と価格を比較して決定 |
| microSD / ストレージ | ○ | 要調査 | OS・アプリ・キャッシュ用 |
| 電源アダプタ | ○ | 要調査 | Raspberry Pi対応品 |
| HDMIケーブル等 | ○ | 要調査 | ディスプレイ接続用 |
| ディスプレイ | ○ | 要調査 | サイズ・解像度・消費電力を比較 |
| 3Dプリント外装 | ○ | 要調査 | 外注予定 |
| その他ケーブル類 | ○ | 要調査 | 必要に応じて購入 |

### 予算方針

- 総額5～6万円以内を目標
- Raspberry Piは必要十分な性能を選択
- ディスプレイは新品に限定しない
- ケーブル類は必要最小限
- 3Dプリントは設計完成後に外注
- クラウドは無料枠を優先
- 継続的な月額費用はできるだけ抑える

## 15. MVPの定義

最初の完成目標は、以下とする。

> **Raspberry Piに接続したディスプレイ上で、時計を常時表示しながら、予定・気温・天気予報などの情報を一定間隔で自動的に切り替えて表示できること。**

MVPではクラウド管理やスマートフォン操作を必須としない。

まずローカル環境で「使えるサイネージ」を完成させ、その後クラウド・Web管理機能を追加する。

## 16. 成功条件

以下を満たした時点で、個人利用可能な完成版とする。

- 毎日電源を入れるだけで利用できる
- 時計が常時表示される
- 必要な情報が自動表示される
- 写真などの新しいコンテンツを追加できる
- ネットワーク障害時にも最低限の表示を継続できる
- スマートフォン/PCから設定変更できる
- 長期間安定して動作する
- 自分自身が「毎日使いたい」と思える

## 17. プロジェクトの基本方針

> **作ること自体を目的にせず、実際に使えるものを作りながら、Raspberry Pi・組み込み・Web・クラウド・IoTを横断的に学ぶ。**

小さく作って動かし、使ってみて、改善する。

AIを活用して開発速度を上げつつ、設計・技術選定・検証・レビューは自分自身が主体となって行う。
