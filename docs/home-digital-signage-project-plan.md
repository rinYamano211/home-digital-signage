# Home Digital Signage

## 1. プロジェクト概要

Raspberry Pi とディスプレイを利用した、個人向けのデジタルサイネージを開発する。

自宅に設置したディスプレイへ時計・日付・曜日を常時表示しながら、今日の予定 → 今日の天気 → 週間天気を自動的に切り替えて表示する。

将来的にはスマートフォンやPCから表示内容を管理できるようにし、クラウドとRaspberry Piを組み合わせたIoT/エッジシステムへ発展させる。

本プロジェクトでは、単にサイネージを完成させるだけでなく、開発を通じて以下の技術領域を学習する。

- Raspberry Pi / Linux
- 組み込み・エッジデバイス
- Webアプリケーション
- API / HTTP通信
- クラウド
- データベース
- デバイスとクラウド間の通信
- CI/CD・テスト・監視
- AI駆動開発
- アジャイル開発

## 2. プロジェクトの目的

### 2.1 Raspberry Piを使う

Raspberry Piを実際のエッジデバイスとして利用し、Linux上でアプリケーションを動作させる。

### 2.2 デジタルサイネージの仕組みを理解する

「コンテンツを作って画面に表示する」だけではなく、

- コンテンツ管理
- 表示制御
- データ取得
- ネットワーク通信
- デバイス側でのキャッシュ
- 自動起動
- 障害時の復旧

など、デジタルサイネージを構成する要素を実際に実装する。

### 2.3 組み込み・クラウド技術を学ぶ

Raspberry Pi側のソフトウェアとクラウド側のサービスを連携させ、エッジデバイスとクラウドが連携するシステムを構築する。

## 4. 表示する情報

### 4.1 MVP

| 表示領域 | 項目 | 内容 |
|---|---|---|
| 固定表示 | 時計・日付・曜日 | メインコンテンツの切り替え中も常時表示 |
| 自動切り替え：1 | 今日の予定 | 当日の予定 |
| 自動切り替え：2 | 今日の天気 | 現在の天気・屋外気温、今日の時間別天気、短時間降雨情報 |
| 自動切り替え：3 | 週間天気 | 今日を含む7日間 |

降水確率はMVPの天気情報に含める。詳細な表示項目は[要件定義](requirements.md)を参照する。

### 4.2 将来追加（Future）

将来的に新しい表示コンテンツを追加できるよう、表示機能は拡張可能な構造を目指す。

候補：

- 写真
- ニュース
- 株価
- カレンダーの別表示形式・拡張機能（月・週など。予定表示そのものはMVP）
- 湿度
- 今日のタスク
- お知らせ
- MVPに含まれない外部API情報
- Raspberry Pi自身の状態をサイネージ上に表示する機能
  - CPU温度
  - CPU使用率
  - メモリ使用量
  - ストレージ使用量
  - ネットワーク状態

運用上の状態確認と、サイネージの表示コンテンツとして追加することは区別する。

## 5. 表示仕様

### 5.1 固定表示領域

時計・日付・曜日を常時表示し、他のコンテンツが切り替わっても維持する。
時計は24時間表記とし、秒はMVPでは表示しない。

配置などの具体的なUIはIssue #5で設計する。時刻未同期時などの詳細動作は[要件定義](requirements.md)で管理する。

### 5.2 メインコンテンツ

MVPでは以下の固定順で自動的に切り替える。

```text
今日の予定
 ↓
今日の天気
 ↓
週間天気
 ↓
今日の予定
 ↓
...
```

表示時間は設定値として保持する。MVPには利用者が変更する機能を設けず、具体的な時間は実機で視認性を確認して調整する。
利用者による表示時間・表示順・コンテンツON/OFFの変更はFutureとする。写真はMVPの切り替え対象に含めない。

### 5.3 拡張性

新しいコンテンツを追加する際に、既存機能への影響を最小限にする。
コンテンツ単位で独立して追加できる構造を目指し、将来の写真などのFutureコンテンツ追加を妨げないようにする。

具体的なソフトウェア構造やインターフェースは、Issue #3のシステムアーキテクチャ設計で決定する。

## 7. 最終目標

### 個人で不便なく日常利用できること

企業向けの大規模なサイネージシステムではなく、自宅で継続的に利用できる品質を目標とする。

MVPでは以下を実現する。

- Raspberry Piの電源を入れると自動起動する
- ネットワークに接続すると必要な情報を取得できる
- 時計・日付・曜日を固定表示する
- 今日の予定 → 今日の天気 → 週間天気を自動切り替えする
- 一時的な通信障害があっても利用可能な情報を表示する
- Raspberry Piの再起動・アプリ異常終了から自動復旧する
- 長時間稼働できる

将来的には表示内容を容易に追加・変更できるようにし、スマートフォンからの操作や高度なカスタマイズへ発展させる。
これらの利用者向け管理・カスタマイズ機能はFutureとして扱う。

## 8. ハードウェア予算

総予算は **50,000～60,000円程度** を目標とする。
必要十分な性能と費用を比較し、以下の構成を選定した。

### 選定済みの構成

| 項目 | 選定内容 |
|---|---|
| 本体 | Raspberry Pi 5 2GB |
| 冷却 | Raspberry Pi 5 Official Active Cooler |
| 本体電源 | Raspberry Pi 27W USB-C Power Supply |
| ディスプレイ | 10.1インチ、1280×800、IPS、500cd/m²、Mini HDMI入力、USB-C 5V/2A給電 |
| 給電構成 | Raspberry Piとディスプレイは独立給電 |
| ストレージ | SanDisk High Endurance 64GB microSD |

記録済みの電子部品・配線関係の合計は **41,387円**。個別の価格・購入状況は[ハードウェア検討](hardware.md)で管理する。

### 外装と予算方針

専用外装・壁掛け方法・最終的な筐体構造は未決定。実機を踏まえて詳細設計する。
MVPでは机上での動作検証を許容し、専用外装・壁掛けはv1.0で扱う。

- 外装等を含む総予算目標は50,000～60,000円
- ケーブル類は必要最小限とする
- 3Dプリント外装の外注は検討案として、筐体詳細設計で具体化する
- クラウド利用時は無料枠を優先し、継続的な月額費用はできるだけ抑える

## 15. MVPの定義

最初の完成目標は、以下とする。

> **Raspberry Piに接続したディスプレイ上で時計・日付・曜日を常時表示しながら、「今日の予定」「今日の天気」「週間天気」を自動的に切り替えて表示し、家庭内で継続利用できるサイネージを完成させる。**

クラウド管理、スマートフォン/PCからの管理、写真、ニュース、株価、利用者によるレイアウト・コンテンツ・切り替え設定の変更はMVP対象外のFutureとする。

まずRaspberry Pi上で動作する「使えるサイネージ」を完成させ、その後クラウド管理・Web管理機能等を追加する。

詳細なMVP要件と受入条件は[要件定義](requirements.md)および[Issue #13](https://github.com/rinYamano211/home-digital-signage/issues/13)を参照する。Issue #13はMVP v0.1の受入確認として扱う。
