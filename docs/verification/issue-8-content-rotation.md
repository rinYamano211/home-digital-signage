# Issue #8：コンテンツの自動切替の実機確認

## 範囲と状態

[Frontend開発手順 第10章](../frontend-development.md#10-コンテンツの自動切替issue-8)で実装したコンテンツの自動切替（PR #84）を、[第7章](../frontend-development.md#7-raspberry-piでの実機確認)と同じ手順でRaspberry Piで確認した。確認はユーザーが目視とストップウォッチで行った。

- 確認日：2026-11-07
- 対象：PR #84（Merge Commit 1b12b24）の実装。Pi上の成果物とCommitの照合は記録していない
- 環境：Raspberry Pi・Raspberry Pi OS・Chromium（Kioskモード）、1280×800
- 成果物：`npm run build:frontend`・`npm run build:frontend:verify`で生成した`dist/frontend/`（通常画面）・`dist/frontend-verify/`（検証画面）
- 通常画面のコンテンツは、#9・#10が入るまでの仮パネル（コンテンツ名だけ）である（第10章 10.7）

### 切替間隔の実測

スマートフォンのストップウォッチで、各コンテンツの表示時間を1回ずつ計測した。

| コンテンツ | 実測    |
| ---------- | ------- |
| 今日の予定 | 9.83秒  |
| 今日の天気 | 9.96秒  |
| 週間天気   | 10.10秒 |
| 平均       | 9.96秒  |

- 設定値（`src/frontend/content/rotation-config.ts`）は各10秒（`10_000`ミリ秒）。
- 実測と10秒との差は最大0.17秒で、手動計測の誤差を含む。Timerの精度を評価したものではない。設定値どおりに切り替わることは、自動テスト（Vitest・Fake Timer）で確認している。

| No. | 条件                                      | 確認した表示・動作                                              | 結果 |

| 10  | 今日の予定だけ表示可                      | 今日の予定を表示し続け、切り替わらない                          | PASS |
| 11  | 今日の天気だけ表示可                      | 今日の天気を表示し続け、切り替わらない                          | PASS |
| 12  | 週間天気だけ表示可                        | 週間天気を表示し続け、切り替わらない                            | PASS |

## Issue #8の完了条件との対応

| 完了条件                                                   | 確認方法                                                                                 |
| ---------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| 時計・日付・曜日を表示したままメインコンテンツが切り替わる | 実機 No.5                                                                                |
| 「今日の予定 → 今日の天気 → 週間天気」の順序で繰り返す     | 実機 No.3・4、自動テスト                                                                 |
