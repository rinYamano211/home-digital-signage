どこに置く？

ソファから、ちらっと見て読める大きさ

置き場所はリビングの壁です。夜もつけっぱなしで寝る場所からも見えるので、真っ白・真っ黒を避けた、まぶしくない配色にしています。

中身はなに？

手のひらサイズのコンピューターが、画面の裏に

画面の裏にRaspberry Pi 5を取り付けて、ケーブル2本で画面とつなぎます。キーボードもマウスもつながず、設定や更新はPCからネットワーク越し（SSH）で行います。

  • Raspberry Pi 5 2GBサイネージの頭脳14,780円
  • 10.1インチ ディスプレイ＋HDMIケーブル1280×800、ベゼルが細め14,980円
  • microSD 64GB（高耐久）24時間書き込んでも長持ちする種類4,142円
  • 公式 27W USB-C 電源Pi 5に必要な電力をしっかり2,750円
  • ディスプレイ用電源・ケーブル・スリーブ配線をまとめて目立たなくする3,635円
  • Active Cooler小さなファン付きの冷却1,100円
050,00060,000円

電子部品と配線で 41,387円。予算は5〜6万円で、残りはRTC電池と3Dプリントの筐体に使います。

データの旅

天気や予定は、こうやって画面まで届く

集める係（Backend）と見せる係（Frontend）を分けています。集める係は取ってきた最新の状態をデータベースに置いておくだけで、何をいつ表示するかは見せる係が決めます。

それぞれのリズム

情報ごとに、取りに行く間隔がちがう

雨はすぐ変わるので5分ごと、週間天気はめったに変わらないので6時間ごと。1日に何回インターネットへ取りに行くかを、同じ物差しで並べました。目盛りの1本が1回分です。

期限切れの情報は表示しません。古い天気を「今の天気」のように見せないためです。間隔と期限は暫定の値で、実機で使いながら調整します。

失敗しても、あきらめない

Wi-Fiが切れたら、間をあけて何度も取りに行く

取得に失敗すると、待つ時間を1分、2分、4分…と少しずつ伸ばしながら取り直します（Backoff）。以前は最大30分まで伸びて、Wi-Fiが戻っても30分近く待つことがありました。11月21日に上限を5分に縮めました。

AIと一緒に作る

AIは手を動かし、決めるのは自分

コードや文書の多くはClaude CodeとCodexが書いています。設計の変更やIssueへの書き込み、Mergeは、毎回自分が確認してから進めます。ルールはAGENTS.mdにまとめています。

設計docsに決めたことを書くdocs:
Backend集める係を作るfeat(backend):
画面見せる係を作るfeat(frontend):
実機確認Piで試して記録docs/verification

たとえば雨の予報（#93）は、PR #99〜#107の9本で仕上げました。作業のたびに、自動テストとLintが通ることを確かめています。
