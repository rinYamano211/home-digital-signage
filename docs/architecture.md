# システムアーキテクチャ設計

## 1. このドキュメントの目的

Home Digital Signage のMVP要件を実現するため、
システム全体の構成、各コンポーネントの責務、
データ・状態の流れ、障害時の動作などを設計する。

具体的な技術・ライブラリ・外部サービスの選定は、
原則として Issue #4「技術スタックを選定する」で行う。
