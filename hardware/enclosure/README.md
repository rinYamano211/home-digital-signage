# 筐体CAD（CadQuery）

Issue #20の筐体CADのソース。寸法・要件の出典は[筐体要件・実測寸法・取付条件](../../docs/enclosure-requirements.md)（Issue #19）。

## 環境の作り方（Windows）

CadQueryは、Repoの外のvenv（このプロジェクト専用のPython環境）に入れる。Repoの中に作ると、Windowsのパスの長さの上限（260文字）を超えてインストールに失敗するため。

- 場所：`C:\Users\<ユーザー名>\.venvs\hds-enclosure`
- 確認した版：Python 3.13.7、CadQuery 2.8.0（`requirements.txt`で固定）

```powershell
python -m venv $env:USERPROFILE\.venvs\hds-enclosure
& $env:USERPROFILE\.venvs\hds-enclosure\Scripts\python -m pip install -r hardware/enclosure/requirements.txt
```

消すときは、venvのフォルダを削除する。

`src`のコードが直接使うライブラリのうち、CadQuery以外のnumpy・scipy・vtk・contourpy（輪郭の計算。vtkが使うmatplotlibと一緒に入る）は、CadQueryと一緒に入る（`requirements.txt`には書いていない）。確認した版：numpy 2.5.5、scipy 1.18.1、vtk 9.6.2、contourpy 1.4.0。CadQueryの版を変えるときは、これらが入ること・`test_signature.py`が通ることを確かめる。

## 実行

Repoのルートで実行する。

```powershell
& $env:USERPROFILE\.venvs\hds-enclosure\Scripts\python hardware/enclosure/src/export.py
```

参照モデルの各部品の範囲（X・Y・奥行き）を表示し、`hardware/enclosure/out/`に図（SVG）を出力する。SVGはブラウザで開いて確認する。

```powershell
& $env:USERPROFILE\.venvs\hds-enclosure\Scripts\python hardware/enclosure/src/check.py
```

筐体の確認をする。1つでもNGがあれば、終了コード1で終わる。

- 形状：各部品が正しい立体で、1つのつながった塊か
- 干渉：各部品と参照モデル、部品どうしが重なる体積が0か
- 接触：押さえ板・上部ストッパー・リアカバーが、決めた相手に当たる・載るか（部品を相手の側へ少し動かすと重なることで確かめる）
- ネジ：リアカバーの6か所で、カバーの通し穴・シャーシのボスの上面・下穴がそろっているか
- 保持：リアカバーがなくても、Displayの上下を押さえる部品がシャーシに付いているか
- 前面の縁：ガラスに被る幅が、表示領域にかからないか（Displayが隙間の分だけ動いても1.0以上の余裕）
- 造形範囲：各部品がプリンタの造形範囲（320×320から余裕10を引いた310）に収まるか
- 刻印：線と線の間・線幅・溝の幅、彫れているか、刻印の底から裏までの残りの厚み、窓・穴・スタンドからの距離
- 卓上スタンド：重さの中心が前後・左右の支点の内側に余裕（15以上）をもってあるか、本体の下面（配線口・吸気のスリット）と机の間に隙間（5以上）があるか

自動の確認で保証できるのは、CADの形の上での重なり・接触・位置だけ。組み付けられるか、保持力・強度・温度は、試作で確かめる。

## 座標

- `params.py`は、docsと同じ座標で書く：Displayを正面から見て左下の角が原点。X＝右、Y＝上、Z＝正面のガラス面から背面への奥行き。
- この座標は左手系のため、CADの中では`reference.to_cad`でZの符号を反転する（CADのZ＝−奥行き）。反転しないと、実物の鏡像になる。

## 参照モデル

実測値と仮定から作った、暫定の「筐体が入ってはいけない範囲」を、少し大きめの箱で表す。

- 実物の細かい形は再現していない。
- 参照モデルと重ならないことは、実機に組み付けられることを保証しない。組み付けられるかは試作で確かめる。
- 筐体の設計を進めるときに、必要に応じて形を細かくする。

| 名前            | 中身                                                                                                                                                  |
| --------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| `display`       | Display本体（薄い部分＋下側の基板がある部分。基板は左右いっぱいと仮定）                                                                               |
| `tabs`          | 下部の固定耳2つ（穴あき。穴の中心のYは仮定。下の円弧の中心と穴の中心は、Xが0.1ずれる）                                                                |
| `display_plugs` | 左側面の端子に挿したプラグ＋ケーブル（Zは基準面が未確認のため余裕を足す）                                                                             |
| `pi`            | Pi 5＋Active Cooler＋スペーサー（基板の外形は公式値、高さは仮定を含む計算値に余裕を足す）                                                             |
| `pi_plugs`      | Piの下側に挿したプラグ（X位置を測っていないため、基板の幅いっぱい・Piの高さいっぱいとする。安全側だが大きすぎるため、干渉が出すぎる場合は細かくする） |
| `rtc_space`     | RTC Battery（任意・後付け）を置くために空けておく範囲。Piの左の基板の上に25×25×高さ10（仮定。実物・公式資料の寸法は未確認）                           |

仮定と余裕の量は`params.py`に書いてある。強度・温度・組立適合性は検証していない。

### 固定耳の押さえ板（Displayの主固定）

PR #149のレビューで、固定耳の穴にネジを通す方式では位置のずれをほとんど吸収できないと分かった（耳の穴3.0にM3のネジでは隙間がなく、左右の穴の間隔約219は測定の誤差と印刷の縮みでずれるおそれがある）。ユーザーの判断で、押さえ板で挟む方式にした（2026-11-27）。

- 耳の穴にはネジを通さない。耳の後ろに押さえ板を当て、耳の内側の隣に立てたボスへM3タッピングネジで留める。板が耳を前へ押し、Displayのガラスを前面の縁に押し付ける。耳の前の台（隙間0.2）は、耳が前へたわみすぎないための受け。
- ボスの上面は耳の背面より0.3低くし、締めると板がたわんで耳を押す。
- 押さえ板は耳の外側の端から1.0内側からボスまで。耳の位置が左右に数mmずれても板が耳に掛かる（`check.py`で、耳に掛かる面積が約43mm²あることを確認）。
- ボスの下穴は深さ8（M3のねじ込みの目安6を満たす）。前面の板の表に2.7残る。
- ボスと耳を受ける台は、前面の板と床の壁の2面につなぐ。
- 押さえ板は別の部品（2枚）。平らに印刷できる。
- 主固定に既存の固定穴を使わないため、`docs/hardware.md` 10.4と`docs/enclosure-requirements.md` 4.2の記述の変更が必要（別のdocs PRで扱う）。
- 締める力、板のたわみ、実機での保持力は確かめていない。

### 配線口の通り方（図面上の確認）

長穴の幅の円が入るため、プラグの断面の対角線が穴の幅より短ければ、向きを合わせて通せる。

| 配線口            | 穴（幅×奥行き方向） | 通すプラグ（幅×厚み） | 断面の対角線 | 判定            |
| ----------------- | ------------------- | --------------------- | ------------ | --------------- |
| Pi用（中央下）    | 18×20               | Pi電源 12×7           | 13.9         | 通る（余裕4.1） |
| Pi用（例外）      | 18×20               | Micro HDMI 14.7×6.9   | 16.2         | 通る（余裕1.8） |
| Display用（左下） | 14×16               | Display電源 11×6.8    | 12.9         | 通る（余裕1.1） |
| Display用（例外） | 14×16               | Mini HDMI 10.9×6.9    | 12.9         | 通る（余裕1.1） |

- 組立の順：ケーブルを外から配線口に通してから、端子に挿す。
- Pi用の穴の位置（X＝133.6）は、Piの電源端子の位置の公式図面の値による参考値。端子の奥行きの位置も測っていないため、穴を奥行き方向に長くした。
- 実物のケーブルの硬さ・曲がり方、2本を同時に通したときの通りやすさは確かめていない。

### ケーブルを留める穴

下フレームの床の、各配線口の横に、結束バンド（幅2.5以下）を通す穴の組を開けた（穴2×4、間隔8）。端子と配線口の間でケーブルを床に留め、外から引っ張っても端子に力がかかりにくくする。

まだ作っていないもの：

- 配線口の縁の丸め（今は端を丸めた長穴だけ。#21で印刷条件と合わせて検討）

## Displayの保持

| 場所 | 部品              | 付く所         | 役割                                                                |
| ---- | ----------------- | -------------- | ------------------------------------------------------------------- |
| 前   | 前面の縁          | シャーシ       | 前への脱落を止める                                                  |
| 下   | 押さえ板2枚       | シャーシのボス | 固定耳を背面から押さえる（主固定）                                  |
| 上   | 上部ストッパー2個 | シャーシの台   | 上側が後ろへ倒れるのを止める（隙間0.3。ガラス・基板に力をかけない） |
| 左右 | 左のリブ・右の壁  | シャーシ       | 左右の位置決め（隙間0.5）                                           |

- どの部品もシャーシに付くため、リアカバーの有無で保持は変わらない。
- 上部ストッパーは、PR #151のレビューで追加した。はじめはリアカバーの柱で上側を押さえていたが、カバーを外すと、下の押さえ板を支点にDisplayの上側が後ろへ倒れるおそれがあった（Display＋Piの重さの中心は、ガラスの前面から約6mm後ろ。下の押さえ板は細い耳を押さえるだけで、倒れる向きの力には弱い）。リアカバーの柱は外した。
- 上部ストッパーは、上の壁から吊った台（下に45度の支え）に、背面からM3タッピングネジで留めるL字の部品。脚の先がDisplayの上側（基板がない薄い部分）の背面に向き合う。表示領域にはかからない。

組立の順（Displayを入れる）：

1. メインシャーシを、前面を下にして置く。
2. Displayを背面から入れ、ガラスを前面の縁に当てる。左のリブと右の壁の間に収める。
3. 押さえ板2枚で、下の固定耳を留める。
4. 上部ストッパー2個を、上の台に留める。
5. Piのケーブルを挿し、結束バンドで床に留める。
6. リアカバーを6本のネジで留める。

外すときは逆の順。ケーブルの抜き差し・microSDの抜き差しは、リアカバーを外せばできる（上部ストッパーと押さえ板は外さなくてよい）。

### 壁掛けの成立条件（設計上の整理。強度は未確認）

キーホールとピクチャーレールは、どちらか一方を使う。

キーホール：

| 項目                   | 条件                                                                                                                                |
| ---------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| 壁のネジ・ピンの頭の径 | 8以下（丸い穴は9）                                                                                                                  |
| 軸の径                 | 4以下（溝の幅は4.5）                                                                                                                |
| 頭の厚み               | 2.5以下（頭が入る空間の深さは3.5。天井まで0.5以上残す。PR #152のレビューで3以下から変更）                                           |
| 壁からの頭の出っ張り   | 壁から頭の下までが2.6以上（板2.4＋隙間0.2）、頭の上までが5.6以下（板2.4＋空間3.5−余裕0.3）。例：頭の厚み2.5なら、頭の下まで2.6〜3.1 |
| 掛け方                 | 丸い穴を頭に合わせて壁に当て、本体を下へ10ずらす。頭が溝の上端（丸い穴の中心から10上）に掛かる                                      |
| 荷重の向き             | 下向き。溝の上端の縁と、頭の空間の台で受ける                                                                                        |
| 頭の空間の周り         | 壁・屋根の厚み2.5                                                                                                                   |
| 印刷                   | 背面を下にすると、頭の空間の屋根は幅9の橋渡し（ブリッジ）になる。サポートなしで印刷できる見込み（試し印刷で確認）                   |

ピクチャーレール（ワイヤー・ひも）：

| 項目               | 条件                                                                                                                                                                                      |
| ------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ワイヤー・ひもの径 | 3以下（穴の径4、内側の溝は4×4）                                                                                                                                                           |
| 通し方             | 片方の穴から入れ、内側の溝（長さ約14）を通して、もう片方の穴から出す。曲がりが2回あるため、硬いワイヤーは通しにくい。やわらかいひも・細い額縁用ワイヤーを使い、必要なら細い針金で引き出す |
| 固定               | 左右の穴の組の間にワイヤーを渡し、両端を結ぶ（またはワイヤー用の金具で留める）。ワイヤーの中央をレールのフックに掛ける                                                                    |
| 印刷               | 内側の溝の屋根は幅4の橋渡しで、サポートなしで印刷できる見込み                                                                                                                             |

共通：

- 荷重の流れ：壁のネジ・ピン（またはワイヤー）→ キーホールの台（またはワイヤーの穴の組）→ 背面の板 → 6本のネジ → シャーシのボス → シャーシ → 前面の縁・押さえ板・上部ストッパー → Display。
- 背面の板が壁に接するため、背面の補助の通気口は壁で塞がれる。主な通気は下（吸気）と上（排気）のスリットで、壁掛けでも塞がれない。背面と壁の間に隙間を取る足を付けるかは、温度を試作で確かめてから決める。
- 壁に掛けると、Display＋Piの重さの中心が壁から約44前にあるため、6本のネジのうち上側に引き抜く向きの力がかかる。タッピングネジを何度も開け閉めすると下穴が緩むため、締めすぎない・回数を減らす。緩んだ場合の対策（太いネジにする等）は試作で確かめる。
- 完成重量・材料・壁掛け部品の耐荷重に基づく強度の確認が必要。完成重量は、Display＋Pi約0.48kgに筐体を加えた値（筐体の重さはPR 5で見積もる）。

### RTC Batteryの空き

- `rtc_space`（Piの左、25×25×高さ10）は仮定の大きさ。実測値ではない。
- Raspberry Pi 5用RTC Batteryの公式の参考寸法との照合はしていない。
- 電池の本体だけでなく、Piの電池用コネクタまでのケーブルと、コネクタの抜き差しの空間も要る。空きの位置は、HDMIケーブルの通り道（Piの左）と重なる可能性がある。
- 後から付けるときは、リアカバーを外して取り付ける。
- 寸法・配線の確認は、後続の設計と試作で行う。

## 卓上スタンド

左右2個のL字のブラケット（`src/stand.py`）。リアカバーは変えずに、キーホールを使って取り付ける。

ネジの条件（壁掛けと同じ）：頭の径6〜8・軸4以下・頭の厚み2.5以下。例：M3トラス頭タッピングネジ。

ネジの長さ（スタンド用）：

- なべ頭・トラス頭のネジの長さ（呼び長さ）は、頭の下からの長さ（頭下長さ）で表す。皿頭は頭を含めた全長で表すため、使わない。
- ねじ込む深さ＝頭下長さ − 浮かせ量（2.6〜3.0）。
- 下穴の深さは9。ねじ込む深さは、M3の目安の6（直径の2倍）以上、下穴の底に当たらない9以下にする。よって頭下長さは9〜11.6。
- M3×10（頭下長さ10）なら、ねじ込む深さは7.0〜7.4で条件を満たす。M3×8は5.0〜5.4で浅く、M3×12は9.0〜9.4で下穴の底に当たるおそれがあるため使わない。
- 実際の保持力（樹脂に直接ねじ込んだときの抜けにくさ）は、試作で確かめる。

使い方：

1. 各ブラケットの下穴（直径2.5、深さ9）にネジをねじ込み、頭の下をブラケットの面から2.6〜3.0浮かせる。浮かせる量はノギスのデプスバー（尻の棒）で測って合わせる。2.6より小さいと板に当たって掛からず、3.1より大きいと頭が空間の天井に当たる。
2. 本体を横に寝かせて置く（どちらかの側面を下に）。ブラケットを手で持ち、ネジの頭をキーホールの丸い穴に入れ、ブラケットを本体の上の方向へ10ずらす。ブラケットの足が本体の下面に当たるまでずらす。2個とも同じように付ける。
3. 置く場所で本体を起こし、2個のブラケットの足と後ろの端を机に着ける。本体の下面が足に載り、背面がブラケットの当たり面（Y 100〜138）に当たる。足の前の縁（高さ3）が、本体が前へ滑るのを止める。
4. 持ち運ぶときは、ブラケットを外す。本体を持ち上げると、ブラケットが自分の重さで下へずれ、丸い穴から外れることがある。

| 項目                 | 値                                                                                                                                                           |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 傾き                 | 後ろへ15度（仮）                                                                                                                                             |
| 本体の下面と机の隙間 | 持ち上げ28（PR #153のレビューで23から変更）。前の下端で約27、一番低い後ろの下端で13.5。Pi用の配線口で16.7以上、Display用で20.8以上、吸気のスリットで15.4以上 |
| ブラケットの位置     | キーホールと同じX（45と165）、幅12                                                                                                                           |
| ブラケットの大きさ   | 177.3×85.5×厚み12。輪郭を床に置いて（厚み12の向きを高さにして）印刷する。ネジの下穴は横向きの小さい穴になる                                                  |
| 背面の当たらない範囲 | Y 100より下は背面から3離す（リアカバーのネジの頭を避ける）                                                                                                   |

安定（`check.py`で確認）：

- 支点と隙間は、CADを傾けたときの一番低い所（実際に机に着く所）から求める。計算の式で作った支点と一致することも確かめる。
- 重さは、Display 407.2g、Pi＋Cooler 69.3gに、筐体（PETGの密度1.27で中身を詰めた〈充填100%〉ときの重さ）の30%・60%・100%を足した3通りで確かめる。筐体が軽いほど重さの中心が前に寄るため、重めの見積もりだけでは安全側にならない。Display・Piは形の中心に重さがあると仮定した。
- 机の上の水平距離で、重さの中心から前の支点まで42.3〜48.5、後ろの支点まで40.0〜46.2、外側のブラケットまで58.7〜64.2（3通りの範囲。PR 5aの外形・持ち上げ28の値）。どれも最小15以上。
- 取り付けの動き（丸い穴の位置で押し込み、10下ろす）の途中で、本体・ネジ（上限の大きさ：頭8×厚み2.5、軸4）がブラケット・カバーに重ならないことを1mmごとに確かめる。
  - 1mmごとの位置しか調べないため、その間の位置で重ならないことを厳密には保証しない（未検証事項）。
  - ただし、動きはどちらも一直線で、ネジが通る溝（幅4.5）と頭の空間（幅9）は動く向きに同じ幅で続く。ブラケットの当たり面は動く向きと平行で、足は最後の位置で初めて本体の下面に当たる。このため、間の位置で急に重なる形はないと考えている。
  - 確実に確かめるには、動く範囲全体を1つの形（掃引した形）にして重なりを調べる方法がある。必要なら#21または試作の前に追加する。
- 値をわざと壊して、確認がNGになることを試した（頭の厚み3.0、後ろの支点を近くする、持ち上げを小さくする、傾き35度、当たり面が背面にめり込む、浮かせ量2.3）。傾き0度（まっすぐ立てる）はNGにならないが、これは安定・隙間とも成り立つため正しい。
- 荷重の流れ（卓上）：本体の重さ → 本体の下面 → ブラケットの足 → 机。後ろへ傾く分は、背面 → ブラケットの当たり面 → 後ろの支点 → 机。キーホールのネジは位置決めで、重さはほとんどかからない。

未確認：

- 実際の重さの中心（印刷の充填率で変わる）、机の上で滑らないか（滑り止めのシールを貼るか）、ブラケットの強度、触ったときにぐらつかないか。試作で確かめる。
- 傾きの角度は見やすさで決める。変える場合は`STAND_TILT_DEG`を変え、`check.py`で安定と隙間を確かめ直す。

### 形の管理

- 正本は「線の中心の道筋＋線幅」。ブランド用のSVG（`out/phos-symbol.svg`・`out/phos-mark.svg`・`out/phos-back-text.svg`）は、これをそのまま線で描く
- 刻印の形は、同じ線に「線と線の間が`SIGN_MIN_GAP`（0.6）より狭い所を埋める」処理を足したもの（造形のための調整）。SVGとの差は埋めた所だけ
- `signature.py`は、SVGとの差（埋めたか所・面積・元の線の縁からの最大の距離）を表示する
- CADの刻印は、刻印の形（埋めたあと）の輪郭から作る。画素の内外からの距離の0の線を輪郭にし、形のずれ0.005以下で点を減らす。輪郭の面積は画素の面積と一致する（マーク90.38 mm²、背面112.58 mm²）

### 寸法の作り方

- 文字は、高さ・線幅から直接作る。線の中心を「線幅/2〜高さ−線幅/2」に置くので、線幅を変えても、線の外側までの高さは決めた高さのまま。横の寸法は高さに対する比
- シンボルは、基準の形の中心線を「高さ−線幅」に合わせて拡大・縮小する。線幅は拡大・縮小しない
- `test_signature.py`で、高さ・線幅を何通りか変えても、外形が決めた寸法になることを確かめる（全部の文字）

寸法の許容範囲（`signature.RANGES`）。範囲の外の値や、条件を満たさない組み合わせは、形を作る前にエラー（`ValueError`）にする：

| 値                                                 | 範囲      |
| -------------------------------------------------- | --------- |
| `SIGN_SYMBOL_H`（シンボルの高さ）                  | 12〜24    |
| `SIGN_SYMBOL_LINE`（シンボルの線幅）               | 0.6〜1.5  |
| `SIGN_LETTER_H`（文字の高さ）                      | 3.5〜6.0  |
| `SIGN_LETTER_LINE`（文字の線幅。前面・背面で共通） | 0.5〜1.0  |
| `SIGN_LETTER_GAP`（字間）                          | 1.0〜5.0  |
| `SIGN_STACK_GAP`（シンボルとロゴの間）             | 3.0〜10.0 |
| `SIGN_MIN_GAP`（線と線の間の最小）                 | 0.4〜1.0  |
| `SIGN_DEPTH`（刻印の深さ）                         | 0.2〜0.8  |
| `SIGN_BACK_LETTER_H`（背面の文字の高さ）           | 3.5〜6.0  |
| `SIGN_BACK_LETTER_GAP`（背面の字間）               | 1.0〜5.0  |
| `SIGN_BACK_LINE_GAP`（背面の行間）                 | 1.5〜6.0  |

- 組み合わせの条件：文字の中の隙間（Sの上下の曲線の間・Eの横線の間、Pの丸い部分の内側、Bの上の丸い部分の内側）が`SIGN_MIN_GAP`以上（前面・背面の文字の高さそれぞれで）。字間が`SIGN_MIN_GAP`以上。シンボルの線は文字の線より細くしない。背面の刻印に形のない文字がない
- 範囲は、FDM（ノズル0.4）での刻印と、前面の左の余白（幅約61）に収まることを目安にした設計の値。範囲の中でも、最終の確認は下の確認とスライサーで行う

### 確認

2D（`signature.py`・`check.py`。NGがあれば終了コード1）：

- 線と線の間（刻印しない所）：どの点も、その中に収まる直径0.6の円に含まれること。幅0.6より狭い帯・とがった角・細い切れ込みは、場所を問わず見つかり、位置を表示する
- 線（刻印する所）：どの点も、その中に収まる直径＝一番細い線幅の円に含まれること
- 溝の一番広い所（溝に入る一番大きい円の直径）：ブリッジの長さの目安。上限3.0（仮定）
- 2Dの画素（0.02mm）で調べるため、距離は1画素分の差を許し、大きさ0.1以下のかたまりは数えない（円がちょうど収まる所で、画素に分けた誤差だけで出る点。背面のSで出た）
- わざと狭くした形（間0.4の平行な2本、V字に開く2本、幅0.5の線）で、狭い所が見つかることをテストで確かめる

CAD（`check.py`）：

- 彫れているか：刻印なしの部品との体積の差が「面積×深さ」と合うこと（引き算が失敗すると合わない）
- 残りの厚み（2通りで測る。最小`SIGN_MIN_REMAIN`＝1.2）
  - 四角の範囲：刻印の外形を囲む四角の下に、材料が続く厚み（刻印の形より広いため安全側）。体積で調べるため、点ごとの厚みではない
  - 断面：刻印の底の点（線の中心を約0.5ごと、輪郭の点）から内側へ直線を伸ばし、裏の面に最初に当たるまでの距離。点ごとの実際の厚み（前面405点、背面842点）
- 位置：前面は窓・外周の面取りから、背面は通気口・ネジの穴・キーホール・ワイヤーの穴・スタンド・外周の面取りから`SIGN_MARGIN`（3.0）以上
- わざと壊した確認：深さ0.8で最小1.3にすると、残りの厚みが四角の範囲で1.19、断面で1.20になりNG。背面の刻印を通気口に重ねると、体積・残りの厚み・位置がNG。左のスタンドに寄せると位置がNG（2.5）
- 計算を軽くするため、輪郭の点が多い型との重なりは使わない（重なり・点の内外の計算は1回で十数秒かかる）

## 印刷用データ（#21）

本印刷用データ（部品ごとのSTL）は`src/export_print.py`で書き出し、`print/full/`に置く。部品の一覧・数・向き・重さの見積もりは`print/full/manifest.md`。

```powershell
& $env:USERPROFILE\.venvs\hds-enclosure\Scripts\python hardware/enclosure/src/export_print.py
```

- 形式：STL（バイナリ）、単位mm。各部品を印刷の向き（docs/enclosure-design.md 2章）で床（Z=0）に置く。向きは実物の形（`reference.to_cad`で直した形）を回すだけで、鏡像にしない
- 分割の細かさ：弦の誤差0.01mm・角度0.1ラジアン。CadQueryの書き出しは細かさを形の大きさに対する比で扱い、前に作った分割を使い回すため、分割を消してから長さで決めた細かさで作り直す（小さい丸い穴が粗くならないように）
- 書き出したSTLを読み直して確かめる：Zの最小が0、外形がCADと一致（0.05以内。CADは面の形から求めた正確な外形）、体積がCADと一致（0.5%以内）で面の向きが外向き、閉じた形（どの辺も2つの三角形で共有）、面の向きがそろっている（どの辺も「a→b」と「b→a」が1回ずつ）、面積0の三角形がない（頂点の重なりと、一直線に並んだ3点の両方）、床に着く面がある
- いったん一時フォルダに書き出して確かめ、全部OKのときだけ`print/full/`を置き換える。NGのときは`print/full/`を変えずに終了コード1で終わる（NGのデータを印刷用と取り違えないため）。置き換えは、隣に作った`full.new`へ全部コピーしてから、名前の変更で入れ替える。コピーや入れ替えの途中で失敗しても、前の`print/full/`が残る
- 頂点の周りの形の不具合（2つの面の束が1点だけで接する等）は確かめていない。CADの段階で各部品が正しい1つの立体であることを`check.py`で確かめており、上の辺の確認とあわせて十分と判断した（実装の手間に比べて得るものが小さい）
- `manifest.md`には、各STLのSHA-256（先頭16文字）と「CADのソースの指紋」（`src/*.py`〈テストを除く〉を改行LFにそろえたもののSHA-256の先頭12文字）を書く。同じソースからは同じSTLになる
- `--verify`を付けて実行すると、`print/full/`を変えずに一時フォルダへ作り直し、Commit済みのSTL・`manifest.md`と一致するかを確かめる（一致しなければ終了コード1）。ソースを変えたあとにデータを作り直し忘れていないかの確認に使う
- 部品の数：メインシャーシ1、リアカバー1、押さえ板2、上部ストッパー2、スタンドのブラケット2（任意）。STLは1個分なので、スライサーで数を増やす
