# 印刷の手順（印刷当日に使う）

Issue #21。印刷は実家のプリンタで、2026-12-25〜30のどこかで行う。当日はPCでCADを作り直さずに済むよう、必要なデータはこのフォルダに前もって用意してある。iPadのブラウザ（GitHub）でこの手順書・各`manifest.md`を見られる。

| フォルダ         | 中身                                                                 |
| ---------------- | -------------------------------------------------------------------- |
| `trial/`         | 仮印刷用のテストピース4つ（約20 g）                                  |
| `full/`          | 本印刷用の部品（STLは1個分。数はスライサーで増やす）                 |
| `full-variants/` | 本印刷の予備：下穴の径だけを2.4・2.6に変えたメインシャーシとスタンド |

データは`hardware/enclosure/src/export_print.py`で書き出したもの。手で編集しない。各フォルダの`manifest.md`に、部品の数・印刷の向き・外形・重さの見積もり・SHA-256がある。

## 1. 持っていく・用意するもの

- 印刷用データ：このフォルダ。USBメモリ等に入れるか、実家のPCでGitHubからダウンロードする
- ネジ（2章）
- 材料：黒め（艶消し）のPETGが第一候補（熱に強め）。使えなければPLA（印刷しやすいが熱に弱く、Piの近くで変形するおそれがある）。ASA・ABSは囲いのあるプリンタが要る
- iPad：この手順書・manifest・画像（`hardware/enclosure/out/render-*.png`）を見る

## 2. ネジの調達一覧

M3タッピングネジ（樹脂に直接ねじ込む）。頭はなべ頭かトラス頭（皿頭は使わない）。長さは頭下長さ（頭の下から先まで）。

| 場所                          | 数   | 頭下長さの範囲 | 候補                                 |
| ----------------------------- | ---- | -------------- | ------------------------------------ |
| リアカバー → シャーシのボス   | 6    | 8.4〜12.4      | M3×10                                |
| 押さえ板 → シャーシのボス     | 2    | 8.5〜10.5      | M3×10                                |
| 上部ストッパー → シャーシの台 | 2    | 8.5〜10.5      | M3×10                                |
| 卓上スタンド（任意）          | 2    | 10             | M3×10（頭の径6〜8・頭の厚み2.5以下） |
| 予備・仮印刷の下穴の確認用    | 数本 |                | M3×10                                |

- 範囲はdocs/enclosure-design.md 2章の計算。全部M3×10で範囲に入る
- 壁掛け（壁側）のネジ・ピン・ワイヤーは、設置場所に合わせて別に用意する（キーホールは頭の径8以下・軸4以下）。完成重量（約0.86 kg。充填100%の重めの見積もり）に足りる耐荷重のものを、製品の表示で選ぶ。ピクチャーレールのフックも同じ

## 3. 当日の流れ

### 3.1 プリンタ・スライサーの確認（最初に）

- プリンタの機種、造形範囲（320×320を想定。全部の部品がブリム込みで310以内）、高さの上限（メインシャーシは49.4必要）
- 使える材料
- スライサーでSTLを読み込み、単位（mm）・大きさ（manifestの外形と同じか）・向き（床に着く面）を確かめる。前面の刻印が、前から見て正しい向きに読めるか（鏡像になっていないか）
- 印刷条件の候補：ノズル0.4、層の高さ0.2、外周の壁3本以上、充填20〜30%、ブリム5（大きい部品）。サポートは原則なし。スライサーのプレビューで、薄い所（背面の角の壁1.34、刻印の線と線の間0.6）が消えていないか、サポートが要る所がないかを見る

### 3.2 仮印刷（`trial/`）

| テストピース         | 見る点                                                                                            | よければ                              | だめなら                                               |
| -------------------- | ------------------------------------------------------------------------------------------------- | ------------------------------------- | ------------------------------------------------------ |
| `trial-engraving`    | 刻印の線・線と線の間が残るか、溝の上が垂れないか、見え方                                          | そのまま                              | 印刷条件（速度・温度・層）を見直す。形を変えるなら後日 |
| `trial-pilot-holes`  | 下穴の径2.3〜2.7（手前の点の数1〜5）のどれで、M3×10がちょうどよく入るか（割れない・空回りしない） | 2.5（点3つ）なら本印刷は`full/`のまま | 4章                                                    |
| `trial-front-corner` | 角R・縁・窓の角の仕上がり、寸法                                                                   | そのまま                              | 印刷条件を見直す                                       |
| `trial-keyhole`      | 壁のネジの頭が丸い穴に入り、上へずらせるか                                                        | そのまま                              | 後日（キーホールの寸法を直す）                         |

下穴のテストピースは径を比べるためのもので、本番のネジ固定部の保持力・耐久性は保証しない（周りの壁や固定のされ方が本番と違う）。

### 3.3 本印刷

| 部品           | 数  | 印刷の向き                         |
| -------------- | --- | ---------------------------------- |
| メインシャーシ | 1   | 前面を下（一番大きく時間がかかる） |
| リアカバー     | 1   | 背面を下                           |
| 押さえ板       | 2   | 平らな面を下                       |

## 4. 仮印刷で下穴を直すとき（PCを使わない）

仮印刷の結果に合わせて、次のどちらかで直す。

| 合った径                   | 直し方                                                                                                                                                               |
| -------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 2.5（点3つ）               | 直さない。`full/`を使う                                                                                                                                              |
| 2.4（点2つ）・2.6（点4つ） | `full-variants/`の`main-chassis-pilot2.4.stl`（または2.6）を`full/main-chassis.stl`の代わりに使う。スタンドを印刷するなら`stand-bracket-pilot2.4.stl`（または2.6）も |
| 2.3（点1つ）・2.7（点5つ） | `full/`を使い、スライサーの穴の補正で直す（下の注意）                                                                                                                |

- スライサーの穴の補正：設定の名前はスライサーで違う（例：Curaの「穴の水平拡張」、PrusaSlicer・OrcaSlicer・Bambu Studioの「XY穴補正」）。当日にスライサーで確かめる。全部の穴に効くため、下穴以外の穴（リアカバーの通し穴3.4、キーホール、配線口・長穴、押さえ板の通し穴など）にも効く。補正を入れたら、スライサーのプレビューでそれらの穴の大きさが大きく変わっていないか（ネジ・ケーブル・壁のネジの頭が通るか）を確かめる。問題がありそうなときは、その部品の本印刷を進めず、後日CADの下穴の径（`params.py`の`SCREW_PILOT_D`）を直してデータを作り直す
- 予備データで変えたのは下穴の径だけ（メインシャーシはリアカバー・押さえ板・上部ストッパーの下穴、スタンドはキーホール用ネジの下穴）。ほかの形は`full/`と同じ
